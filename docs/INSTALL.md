# 폰에 설치하기 (GitHub Pages 웹앱)

앱 코드만 GitHub에 올라가고, **교재와 학습 기록은 폰 안에만** 저장됩니다.

## 1. GitHub 준비 (처음 한 번, 직접)

1. https://github.com/signup 에서 무료 계정을 만듭니다. (이미 있으면 로그인)
2. 오른쪽 위 **+** → **New repository**
   - Repository name: `nihongo-study`
   - **Public** 선택 (무료 계정에서 웹사이트를 만들려면 공개 저장소여야 해요. 교재는 올라가지 않아요)
   - "Add a README file"은 **체크하지 않기** → **Create repository**
3. 만든 저장소에서 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
4. 저장소 주소(예: `https://github.com/내아이디/nihongo-study`)를 Claude Code에게 알려 주세요.
   Claude가 코드를 올릴 때 **GitHub 로그인 창**이 뜨면 직접 로그인합니다.

올린 뒤 2~3분 지나면 앱 주소가 생깁니다: `https://내아이디.github.io/nihongo-study/`

## 2. 폰에 앱 설치

1. 폰 **크롬**에서 위 앱 주소를 엽니다.
2. 오른쪽 위 **⋮ → 홈 화면에 추가**(또는 **앱 설치**)를 누릅니다.
3. 홈 화면의 **일본어** 아이콘으로 엽니다. 이제 인터넷 없이도 열려요.

## 3. 교재 옮기기 (카카오톡)

PC의 이 두 파일을 카카오톡 **나와의 채팅**으로 보내고, 폰에서 각각 **저장**합니다.

| 파일 | 위치 (PC) | 크기 |
|---|---|---|
| 교재 | `어플\books\5ab70b9f895f305a.zip` | 약 50MB |
| 단원 콘텐츠 (33과까지) | `어플\books\5ab70b9f895f305a.content.json` | 약 1.6MB |

앱에서:
1. **라이브러리 → + 교재 추가** → `5ab70b9f895f305a.zip` 선택 (1분 정도 걸려요)
2. 교재를 누르고 맨 아래 **+ 단원 콘텐츠 가져오기** → `5ab70b9f895f305a.content.json` 선택
3. 홈 → **오늘의 학습 시작**

## 4. 꼭 해 둘 것: 백업

폰 브라우저는 저장 공간이 부족하거나 '사이트 데이터 삭제'를 하면 기록이 지워질 수 있어요.
**설정 → 백업 파일 만들기**를 1주일에 한 번 정도 하고, 파일을 카카오톡이나 드라이브에 보관하세요.
복구는 **설정 → 백업 파일로 복구** (교재 이미지는 교재 .zip을 다시 추가하면 채워져요).

## 업데이트

Claude Code가 새 기능을 올리면 폰에서 앱을 **두 번 껐다 켜면** 새 버전이 적용돼요. 학습 기록은 그대로 남아요.
새 단원 콘텐츠가 생기면 `content.json`만 다시 옮겨서 가져오면 돼요 (직접 고친 내용은 유지).
